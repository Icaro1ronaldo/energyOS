# EnergyOS
Platform for the European Energy Market

---

## Overview

EnergyOS is a full-stack real-time platform that tracks and visualises:
- **Electricity prices** — actuals from ENTSO-E, forecasts from internal ML model
- **Energy consumption / load** — actuals from ENTSO-E, forecasts from internal ML model
- **Energy production by type** — actuals from ENTSO-E, forecasts from internal ML model

ENTSO-E is used exclusively for **actual data ingestion**.
All forecasts are generated by an **internal Prophet ML model** trained on historical actuals.

## Data Flow

```
┌────────────────────────────────────────────────────────────┐
│                    REAL-TIME DATA FLOW                     │
│                    (actuals only)                          │
│                                                            │
│  ENTSO-E                                                   │
│     │                                                      │
│     ▼ (every 15 min)                                       │
│  Celery ingestion task                                     │
│     │                                                      │
│     ├──► TimescaleDB (persist, is_forecast=false)          │
│     │                                                      │
│     └──► Redis Pub/Sub (publish event)                     │
│               │                                            │
│               ▼                                            │
│          FastAPI WS handler (subscriber)                   │
│               │                                            │
│               ▼                                            │
│          Connected browser clients (dashboard updates)     │
└────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────┐
│                   HISTORICAL DATA FLOW                     │
│                                                            │
│  Browser requests historical range                         │
│     │                                                      │
│     ▼                                                      │
│  FastAPI REST endpoint                                     │
│     │                                                      │
│     ├──► Redis cache hit? ──► return cached response       │
│     │                                                      │
│     └──► TimescaleDB range query ──► cache ──► return      │
└────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────┐
│                   ML FORECAST DATA FLOW                    │
│                   (all domains, all types)                 │
│                                                            │
│  Daily Celery beat task                                    │
│  runs once per (domain, bidding_zone) combination:         │
│     │                                                      │
│     ├──► load 2y actuals from TimescaleDB (training data)  │
│     ├──► fit / retrain Prophet model                       │
│     ├──► serialize model artifact (.pkl) ──► S3            │
│     ├──► update ml_model_registry in DB                    │
│     ├──► generate 48h forecast                             │
│     └──► write forecast rows to TimescaleDB                │
│               (is_forecast=true)                           │
│                                                            │
│  Covers all domains:                                       │
│  · prices       (per bidding zone)                         │
│  · load         (per bidding zone)                         │
│  · production   (per production type, per bidding zone)    │
│                                                            │
│  Result: unified API — actuals and forecasts served        │
│  from the same endpoints, distinguished by is_forecast     │
└────────────────────────────────────────────────────────────┘
```

## Database Schema

```
energy_prices (hypertable, partitioned by timestamp)
  · timestamp       TIMESTAMPTZ  NOT NULL
  · bidding_zone    TEXT         NOT NULL  (e.g. DE_LU, FR, ES)
  · price_eur_mwh   NUMERIC
  · is_forecast     BOOLEAN      DEFAULT false
  · PRIMARY KEY (timestamp, bidding_zone, is_forecast)

energy_loads (hypertable, partitioned by timestamp)
  · timestamp       TIMESTAMPTZ  NOT NULL
  · bidding_zone    TEXT         NOT NULL
  · load_mw         NUMERIC
  · is_forecast     BOOLEAN      DEFAULT false
  · PRIMARY KEY (timestamp, bidding_zone, is_forecast)

energy_productions (hypertable, partitioned by timestamp)
  · timestamp       TIMESTAMPTZ  NOT NULL
  · bidding_zone    TEXT         NOT NULL
  · production_type TEXT         NOT NULL  (solar, wind_onshore, wind_offshore,
  ·                                         nuclear, hydro_ror, hydro_reservoir,
  ·                                         fossil_gas, fossil_coal, biomass, other)
  · value_mw        NUMERIC
  · is_forecast     BOOLEAN      DEFAULT false
  · PRIMARY KEY (timestamp, bidding_zone, production_type, is_forecast)

ml_model_registry
  · id              UUID         PRIMARY KEY
  · domain          TEXT         NOT NULL  (prices | load | production)
  · bidding_zone    TEXT         NOT NULL
  · production_type TEXT                   (null for prices and load)
  · s3_key          TEXT         NOT NULL  (path to .pkl artifact in S3)
  · trained_at      TIMESTAMPTZ  NOT NULL
  · is_active       BOOLEAN      DEFAULT true

users
  · id              UUID         PRIMARY KEY
  · email           TEXT         UNIQUE NOT NULL
  · hashed_password TEXT         NOT NULL
  · role            TEXT         DEFAULT 'viewer'
  · created_at      TIMESTAMPTZ
```

## Forecast Coverage

| Domain | Forecast source | Horizon |
|---|---|---|
| **Electricity prices** | Internal ML (Prophet), trained on actuals | 48 h |
| **Load / consumption** | Internal ML (Prophet), trained on actuals | 48 h |
| **Production — all types** | Internal ML (Prophet), trained on actuals | 48 h |

> ENTSO-E is used **only** for ingesting actual data.
> No forecast data is fetched from any external API.
> Models are retrained daily and artifacts versioned in S3.

## ENTSO-E Data Sources (Actuals Only)

| Domain | Doc Type | Granularity |
|---|---|---|
| Electricity prices | A44 (realised day-ahead) | Hourly |
| Actual total load | A65 (realised) | 15 min |
| Actual generation per type | A75 (realised) | 15–60 min |
